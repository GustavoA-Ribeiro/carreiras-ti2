# 🧭 Consultor Avançado de Carreiras em TI

Sistema Especialista Baseado em Regras com Tratamento de Incerteza e Pontuação Ponderada desenvolvido em Python e Streamlit.

## 📌 Funcionalidades
- Interface interativa em etapas (Wizard) utilizando Escala Likert (1 a 5).
- Motor de inferência ponderado que calcula a compatibilidade percentual (%) para 10 trilhas de TI.
- Base de conhecimento desacoplada do código fonte (`regras_carreiras.json`).
- Módulo de Análise de Lacunas (Skill Gaps) adaptado ao nível do utilizador.
- Geração de Roadmap personalizado com certificações e projeto de portfólio.
